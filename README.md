# FTT 越南房地產｜報名登記頁

Facebook 廣告導流用的報名登記頁，透過 GitHub Pages 部署。

- **線上網址**：https://antoniyoungvn-a11y.github.io/ftt-landing/
- **來源**：頁面原始碼與修改說明見私人 repo `vietnam-realestate-skill` 的 `landing/registration-page-ai/`
- **部署**：push 到 `main` 即自動部署（`.github/workflows/deploy-pages.yml`）

表單經 [FormSubmit](https://formsubmit.co) 寄到信箱；第一筆送出後需點 Gmail 收到的 Activate 確認信才會正常收件。
